
【环保与双碳领域术语规则 — 本平台是环保、双碳、EHS 行业内容，严格遵守】

1. 歧义默认值：以下词在中文有非环保歧义，一律按环保含义处理：
   - 环评 = 环境影响评价（不译"评估周围"）
   - 排污许可 = 排污许可证制度（不是"排放任何许可"）
   - 碳价 = 碳排放配额价格（不是"煤炭价格"；煤炭价格写作煤价）
   - 履约 = 配额履约（碳市场语境，不是"履约保证金"）
   - 配额 = 碳排放配额（碳市场语境）
   - 绿色工厂 = 工信部门评价认定的绿色工厂（不是"环保的厂房"）
   - 危废 = 危险废物（不是"危险的废弃物泛称"）

2. 以下编号与专名**一字不改**保留，不翻译不加括注：
   - 标准号：GB、GB/T、HJ、HJ/T、DB、DB/T、T/（团体标准）后接的数字与年份，如 GB 12345—2026、HJ 91.2—2025，字母大写、分隔点与一字线保持原样
   - 文号：国办发、环办、环发、部令第 X 号等原样保留
   - 机制缩写：CCER / ETS / MRV / CEA / EU CBAM / IPO（通用）保留英文
   - 污染物缩写：PM2.5、PM10、VOCs、NOx、SO2、COD、BOD、NH3-N、TP、TN 保留原样
   - 国际机构：UNFCCC / IPCC / IEA / UNEP / EPA 保留英文；需要说明时首次译"联合国气候变化框架公约"等全称

3. 常见英文术语的中文写法（首次出现可括注英文，后续用中文）：
   - carbon neutrality = 碳中和；carbon peak = 碳达峰；net-zero = 净零
   - carbon footprint = 碳足迹；carbon sink = 碳汇；offset = 抵销（碳市场语境，不译"抵消"时保持"抵销"）
   - ESG = ESG（保留）；green supply chain = 绿色供应链；circular economy = 循环经济
   - emissions trading = 碳排放权交易；allowance = 配额；compliance deadline = 履约截止日期
   - due diligence = 尽职调查；disclosure = 披露；materiality = 重要性（ESG 语境）
   - hazardous waste = 危险废物；solid waste = 固体废物；leachate = 渗滤液；flue gas = 烟气
   - environmental impact assessment = 环境影响评价（环评）；pollution discharge permit = 排污许可证

4. 机构名对照（英文出现时用官方中文名）：
   - Ministry of Ecology and Environment = 生态环境部
   - National Development and Reform Commission = 国家发展改革委（国家发改委）
   - Ministry of Industry and Information Technology = 工业和信息化部（工信部）
   - State Administration for Market Regulation = 国家市场监督管理总局（市场监管总局）
   - China Environmental Monitoring Station = 中国环境监测总站
   - Shanghai Environment and Energy Exchange = 上海环境能源交易所（上海环交所）

5. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - URL 原样
   - 金额、浓度限值、比例、处罚金额、日期区间必须保留原文的阿拉伯数字和单位（万元、mg/m³、mg/L、%，%；不把"mg/m³"改写成"毫克每立方米"以外的形式）
   - 日期与施行时间保持原文表述，不改写格式
