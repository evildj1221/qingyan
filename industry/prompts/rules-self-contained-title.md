
【标题自洽规则 — 让读者不点开就知道"这是谁的什么事"】

1. 标题必须点出核心主体：文件名 / 标准号 / 机关名 / 公司名 / 项目名。
2. 原标题已经清楚点出主体的：保持原意，不要为改写而改写；标题过长的保留发文机关、文种和核心对象。
3. 原标题只是文号 / 代号 / 没信息量的通稿题（如"一则通知"、"重磅发布"、"重要公告"）时，结合【来源】和正文把主体补进标题。例：原标题"关于开展2026年专项工作的通知" + 来源"生态环境部·政策文件" → "生态环境部部署2026年专项工作"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体标准号或文件名时，用上位词（如"一项水污染物排放标准"）兜底，绝不凭"行业常识"编一个具体标准号 / 文号 / 金额 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：解读 / 分析 / 指南 / 盘点 / 评论这类解释分析类标题，中文标题必须保留这个类型；不能因为正文谈到一份已经存在的文件、标准或处罚，就改写成"发布 / 印发 / 处罚 / 公示"。只有原标题明确宣布了发布、印发、处罚或公示，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机关、文件、标准名。
   例：原标题"环评名单管理新规解读" → "环评名单管理新规解读：企业需要注意什么"，不能写成"生态环境部发布环评新规"。
   例：原标题"这家公司被罚三千万的教训" + 来源和正文明确是危废非法转移案 → "危废非法转移案被罚三千万的合规教训"，不能只写成缺主体的"三千万罚单的教训"。
